# 💰 Gestión de Finanzas Personales

Aplicación web diseñada para facilitar el control de las finanzas personales mediante el registro y seguimiento de ingresos, gastos y presupuestos. Su objetivo es ofrecer una experiencia intuitiva que permita visualizar los movimientos financieros y tomar mejores decisiones económicas.

## 🚀 Características principales

- **Registro de ingresos y gastos:** permite llevar un control de los movimientos financieros.
- **Historial de movimientos:** seguimiento de las transacciones realizadas.
- **Reportes financieros:** visualización de la actividad financiera para facilitar el análisis.
- **Presupuesto mensual:** planificación y control del dinero disponible.
- **Interfaz intuitiva:** diseño enfocado en ofrecer una experiencia de usuario sencilla y agradable.

## ⚙️ Instalación y ejecución

### 1. Clonar el repositorio

```bash
git clone URL_DEL_REPOSITORIO
```

### 2. Entrar al proyecto

```bash
cd nombre-del-proyecto
```

### 3. Instalar dependencias

```bash
npm install
```

### 4. Ejecutar en desarrollo

```bash
npm run dev
```

### 5. Abrir en el navegador

Visita:

```text
http://localhost:3000
```

## 📦 Compilación para producción

Para generar la versión de producción:

```bash
npm run build
```

Para ejecutar la aplicación compilada:

```bash
npm start
```
